# IT_viddil_monitoring 3.0.1

Окрема переносна версія Windows-монітора з дизайном, наближеним до Apple. Версії 1.0 та 2.0 збережено без змін.

## Запуск

Розпакуйте ZIP для x64 (Intel/AMD) або ARM64 і відкрийте `IT_viddil_monitoring_v3.exe`. .NET 10.0.12, WPF, іконку та шрифти вбудовано в програму. Окреме встановлення шрифтів чи .NET не потрібне. Основна ціль — Windows 11. Докладні умови сумісності та підпису — [DISTRIBUTION.md](DISTRIBUTION.md).

## Новий вигляд

У 3.0.1 іконку в шапці та вікні замінено на векторний рисунок з `Icon.xaml`: округла синьо-фіолетова плитка, скляний блиск і білий графік. Іконка EXE має кадри 16, 20, 24, 32, 40, 48, 64, 96, 128 та 256 px. Прев’ю 512 px — `assets/icon-preview.png`.

- Світла тема за замовчуванням, окрема темна тема.
- Напівпрозорі плаваючі панелі з розмиттям власного фону, м’якою тінню та світлими краями.
- Плавні кольорові форми фону, власноруч намальовані у WPF.
- Великі цифри та шрифти Inter / Inter Display із трьома вагами й підтримкою української.
- Сегментований перемикач CPU / ОЗП / I/O, округлий пошук і компактні елементи керування.
- Стабільні контрастні поверхні таблиці й рейтингу, чіткий текст поверх скла.
- На вузькому вікні панелі рейтингу й процесів розташовуються вертикально.

Скло розмиває окремий шар власного фону програми. Робочий стіл не захоплюється. Дві поверхні скла кешуються; без апаратного прискорення та у режимі високої контрастності розмиття фону вимикається. Безперервної анімації або розмиття кожного рядка немає.

## Референс і шрифти

Орієнтир — [iOS and iPadOS 27 UI Kit Apple у Figma](https://www.figma.com/community/file/1651309003795292092/ios-and-ipados-27). У відкритій бібліотеці переглянуто прев’ю Liquid Glass Clear, Regular Medium і Segmented Control. Це самостійна адаптація оформлення для Windows; ресурси, іконки та шрифти Apple у випуск не включено. Нативний матеріал Apple Liquid Glass у WPF не використовується.

[Ліцензія SF](https://developer.apple.com/fonts/) і [ліцензія Apple Design Resources](https://developer.apple.com/apple-design-resources-license/) обмежують використання відповідними платформами Apple та забороняють вбудовування цих ресурсів у Windows-програму. Тому випуск використовує [Inter 4.1](https://rsms.me/inter/), який автор дозволяє вбудовувати за SIL Open Font License 1.1. Повний текст ліцензії й авторство містяться у `Inter-LICENSE.txt` поруч із EXE та у вбудованих ресурсах.

## Показники

За замовчуванням показано середні значення **з моменту відкриття**. Тумблер «Реальний час» перемикає весь екран на поточний інтервал, приблизно одну секунду. Процеси з однаковими назвами об’єднуються, наприклад усі `chrome`.

«Топ 1» — сукупний лідер: частки групи серед усіх виміряних програм за CPU, пам’яттю та I/O додаються з однаковою вагою. Окремі картки показують лідерів кожного ресурсу. Пошук фільтрує рейтинг і таблицю; верхні лідери враховують усі програми. PID і список служб доступні у підказці рядка.

Windows може обмежувати доступ до захищених процесів. I/O — байти читання й запису процесу, а не фізична активність диска. Working set може містити спільні сторінки пам’яті. Служби одного процесу мають спільні лічильники. Ці обмеження зберігаються незалежно від оформлення інтерфейсу.

Сам монітор не включається до таблиці, рейтингу та жодного верхнього лідера. Поточний процес виключається за PID навіть після перейменування EXE; відомі процеси `IT_viddil_monitoring`, `IT_viddil_monitoring_v2` та `IT_viddil_monitoring_v3` також приховані. Фільтр діє в реальному часі та за весь час спостереження, включно із завершеними записами.

## Збірка

Потрібен стабільний .NET 10 SDK на Windows. Із папки `v3`:

```powershell
dotnet restore IT_viddil_monitoring.csproj -r win-x64 --source https://api.nuget.org/v3/index.json
dotnet publish IT_viddil_monitoring.csproj -c Release -r win-x64 --self-contained true --no-restore -o ../releases/v3.0.1/windows-x64
```

Або запустіть `scripts/Build-Portable.ps1`, якщо політика PowerShell вашого комп’ютера дозволяє сценарії. Скрипт створює обидві архітектури, архіви, ліцензію Inter та контрольні суми. Він не змінює захист Windows або старі випуски.
