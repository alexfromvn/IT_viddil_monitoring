IT_viddil_monitoring 3.0.2 — запуск на іншому комп'ютері

1. Розпакуйте ВЕСЬ ZIP у звичайну папку, наприклад на Робочий стіл.
   Не запускайте файли прямо з вікна архіву.

2. Відкрийте «Запустити програму.cmd» подвійним кліком.
   Файл має лежати поруч із IT_viddil_monitoring_v3.exe.
   Адміністраторські права зазвичай не потрібні.

3. Скрипт перевірить EXE за вбудованою контрольною сумою,
   розблокує саме цей файл і відкриє програму.
   Якщо EXE не відповідає відомій збірці, скрипт його не запустить.

4. Надалі можна відкривати EXE безпосередньо з цієї самої папки.

Якщо Windows показує попередження для самого CMD
------------------------------------------------
Для отриманого від автора комплекту відкрийте:
правий клік на «Запустити програму.cmd» → Властивості →
«Розблокувати» → Застосувати → OK. Потім відкрийте CMD знову.
Виконуйте це лише для комплекту з джерела, якому довіряєте.

Якщо запуск усе ще заборонено
----------------------------
Скрипт прибирає мітку завантаження з інтернету у перевіреного EXE.
Цифровий підпис він не додає. Smart App Control, корпоративні
правила чи інші обмеження Windows можуть окремо забороняти запуск.
У такому разі передайте повідомлення адміністратору комп'ютера.

Скрипт не змінює налаштування Defender, SmartScreen, реєстру,
політики PowerShell чи довірених сертифікатів. Нічого не встановлює
і не передає дані в інтернет.

Сумісність
----------
x64 — Windows на 64-бітному процесорі Intel/AMD.
ARM64 — Windows на процесорі ARM, наприклад Snapdragon.
Основна ціль — Windows 11. .NET і шрифти включено до EXE.
Версія ARM64 потребує перевірки запуску на ARM-комп'ютері.
Докладніше — DISTRIBUTION.md та PRIVACY.md поруч із програмою.

Цей CMD впізнає наші випущені збірки 3.0, 3.0.1 та 3.0.2 для x64/ARM64,
включно з першим відкритим випуском GitHub. Для майбутньої нової
збірки потрібен оновлений CMD із контрольною сумою від автора.

Офіційний опис розблокування файлів у Windows:
https://support.microsoft.com/en-gb/windows/security/information-about-the-attachment-manager-in-microsoft-windows

Для перевірки без запуску: «Запустити програму.cmd» --check-only.
Для розблокування без запуску: «Запустити програму.cmd» --unblock-only.
